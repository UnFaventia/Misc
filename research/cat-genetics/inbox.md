# Inbox

Dump new research here: pasted articles, links, half-thoughts, "omg did you know". It doesn't need to be tidy. When an item gets sorted into a topic file, delete it from here and add a line to the log at the bottom.

## Triage checklist (for sorting an item)

1. **Which file?** Colour name → 01 · pattern → 02 · silver/golden → 03 · tortie/white → 04 · C locus → 05 · eyes → 06 · DBE → 07 · shape → 08 · ears/skull/brain → 09 · rare/future → 10 · health → 11. If it fits nowhere, start a new numbered file and add it to the [README](README.md).
2. **Genotype** in calculator notation, or say why it isn't one (descriptive / polygenic / wild-derived).
3. **Calculator status** mark: ✅ 🏷️ 🟡 ❌ 📖 🚫.
4. **Evidence quality:** sequenced variant · pedigree study · breeder report · single anecdote.
5. **Conflicts** with anything already filed → that file's *Source quirks*, plus the ⚠️ column in [00](00-coverage-map.md).
6. If it changes a gap's size or tier, update [00](00-coverage-map.md).
